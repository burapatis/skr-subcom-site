# เว็บไซต์คณะอนุกรรมาธิการการส่งเสริมการเรียนรู้ การศึกษาเอกชน การศึกษาพิเศษ และความเท่าเทียมทางการศึกษา

เว็บไซต์แบบสถิต (static website) จัดทำโดยฝ่ายเลขานุการคณะอนุกรรมาธิการฯ เพื่อนำเสนอกรอบขอบเขต แผนการพิจารณาศึกษา และหลักฐานจากพื้นที่ประกอบการพิจารณาศึกษา (รายงานฉบับสมบูรณ์จะเผยแพร่เมื่อวุฒิสภาให้ความเห็นชอบ)

## โครงสร้างไฟล์

```
site/
├── index.html          หน้าแรก (การ์ดสี่ด้านลิงก์ไปยังขอบเขตแต่ละด้าน)
├── about.html          เกี่ยวกับคณะฯ (บทบาท หน้าที่และอำนาจ)
├── scope.html          กรอบการพิจารณาศึกษา (สี่ชั้น + ตารางจับคู่ + แหล่งกฎหมายอ้างอิง)
│                       มี anchor: #learning #private #special #equity
├── plan.html           แผนการพิจารณาศึกษารายด้าน + ชุดคำถาม
├── results.html        ศูนย์กลางหลักฐานจากพื้นที่ (เส้นเวลา + สามชุดเรื่อง)
├── results/            บทสังเคราะห์และหน้ากิจกรรมดูงาน/รับฟัง
├── documents/          PDF สรุปฝ่ายเลขานุการ (ชื่อไฟล์ภาษาอังกฤษ)
├── contact.html        ติดต่อฝ่ายเลขานุการ
├── assets/
│   ├── css/style.css   ระบบออกแบบทั้งหมด
│   └── js/main.js      แถบการเข้าถึง เมนูมือถือ และเอฟเฟกต์
├── build_site.js       ตัวสร้างหน้าเว็บจากส่วนประกอบร่วม (ใช้ Node.js) — ไม่จำเป็นต่อการเผยแพร่
└── README.md           ไฟล์นี้
```

หมายเหตุ: ไม่มีหน้า "เอกสารเผยแพร่" แยกเมนู ไฟล์สรุปดูงานและรับฟังดาวน์โหลดได้จากหน้าผลการพิจารณาศึกษา

## การนำขึ้นเผยแพร่ (Hosting)

เป็น HTML/CSS/JavaScript ล้วน ไม่ต้องใช้เซิร์ฟเวอร์พิเศษหรือฐานข้อมูล อัปโหลดทั้งโฟลเดอร์ `site/` ขึ้นโฮสติงของหน่วยงาน ตั้งให้ `index.html` เป็นหน้าเริ่มต้น หรือทดสอบในเครื่องด้วย `python3 -m http.server`

## การแก้ไขเนื้อหา

- แก้ข้อความได้โดยตรงในไฟล์ `.html` แต่ละหน้า
- ปรับสี ตัวอักษร ระยะห่าง ได้ที่ตัวแปรส่วนบนของ `assets/css/style.css` (`:root`)
- หากต้องการแก้ส่วนหัว/ส่วนท้ายที่ใช้ร่วมกันทุกหน้า ให้แก้ใน `build_site.js` แล้วสั่ง `node build_site.js`

## ลิงก์เว็บไซต์รับฟังความคิดเห็น

ลิงก์ opinion.thamdee.com ปรากฏในแถบบนสุด ส่วนท้าย หน้าแรก หน้าแผนฯ หน้าผลการพิจารณาศึกษา และหน้าติดต่อ

## การเข้าถึง (Accessibility)

รองรับการปรับขนาดตัวอักษรสามระดับและโหมดความเปรียบต่างสูง (แถบเครื่องมือมุมขวาบน) ใช้งานด้วยแป้นพิมพ์ได้ โครงสร้าง HTML เชิงความหมาย และเคารพการตั้งค่าลดการเคลื่อนไหว
